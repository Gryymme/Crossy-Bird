# Crossy Bird

A C++ OpenGL obstacle-avoidance game for Windows. Guide a bird through branch gaps and falling clouds while gravity pulls it down. Features include scrolling backgrounds, a start menu and countdown, increasing obstacle speed, scoring, a saved high score, sprite-based screens and score digits, and collision screen shake.

## Controls

- **Space:** start the countdown from the menu; return to the menu after game over.
- **W:** flap upward.
- **A / D:** move left / right.
- **S:** move downward.

## Requirements

- Windows with OpenGL support.
- Dev-C++ with an x64 MinGW C++ toolchain. `Makefile.win` was generated by Dev-C++ 5.11 and references its MinGW64 GCC 4.9.2 installation.
- Bundled freeglut and GLEW 2.1.0 headers/libraries in `Dependencies/`, and `stb_image.h` for PNG loading. The project links static GLEW, freeglut, OpenGL and GLU.
- Keep the supplied x64 `freeglut.dll` beside the executable and the toolchain's `bin` directory on PATH.

## Build and run

Open `CrossyBird.dev` in Dev-C++, select the x64 compiler, and rebuild. The project and makefile contain absolute include/library paths for this checkout and the Dev-C++ installation; update those paths in the IDE if either location changes, then regenerate the makefile.

Alternatively, from a PowerShell prompt in the project root with the Dev-C++ MinGW64 `bin` directory on PATH:

```powershell
mingw32-make.exe -B -f Makefile.win
.\CrossyBird.exe
```

Rebuild the supplied executable before running: its original image paths predate the asset move. Use the **project root as the working directory**, including when launching from the IDE. Image paths (`assets/...`) and `highscore.txt` resolve relative to that directory; it must be writable to save high scores. The project does not specify a separate working-directory override.

## Files

- `main.cpp`: game logic, rendering, input, texture loading and high-score persistence.
- `assets/`: all 48 game PNGs, preserving their filenames and image contents.
- `CrossyBird.dev`: Dev-C++ project; `Makefile.win`: generated build instructions.
- `Dependencies/`: bundled freeglut and GLEW packages, left unchanged (including their documentation images).
- `stb_image.h`: bundled image loader.
- `highscore.txt`: persistent high score.
- `CrossyBird.exe`, `main.o`: existing build outputs; root DLLs accompany the project.
